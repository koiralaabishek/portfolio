LxSub — Linux Subsystem for Linux

WSL for Linux desktops & servers. Run, snapshot, clone, and manage isolated distros side-by-side.

A native, ultra-lightweight subsystem for Linux that brings the convenience and isolation of WSL to Linux distributions. Built using modern C++20, Linux Namespaces (PID, Mount, UTS, IPC, Network), Cgroups v2 resource capping, and Copy-on-Write (COW) OverlayFS storage.

Multi-Distro Sandbox Isolation Instantly spin up Ubuntu, Debian, Kali, Arch Linux, Fedora, Alpine, openSUSE, or Rocky Linux side-by-side without hypervisor virtualization.
Instant Point-in-Time Snapshots Create sub-second snapshots and rapid rollback points using lightweight OverlayFS diff layers with zero disk duplication.
Familiar `lxrun` Command Line Utility Intuitive CLI inspired by WSL (`lxrun install <distro>`, `lxrun run`, `lxrun snapshot`, `lxrun clone`, `lxrun stats`).
Cgroups v2 Resource Governance Strict memory, CPU, and process ceiling limits preventing runaway scripts or noisy neighbor workloads.
C++20 Linux Namespaces Cgroups v2 OverlayFS (COW) Systemd Daemon D-Bus IPC CMake
